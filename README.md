# ledger-app
Vue3 + Vite 前端简易记账本
数据自动持久化到浏览器 localStorage，无需后端服务。

## ✨ 功能特性
- 支持收入 / 支出记账，多种收支分类
- 收支流水筛选、删除、清空记录
- 本月收支统计、结余计算
- 支出分类Top5排行
- 关闭页面数据不丢失

## 🚀 本地运行
### 环境要求
安装 Node.js

### 启动步骤
```bash
# 克隆项目
git clone https://github.com/Juhoon1/ledger-app.git
cd ledger-app

# 安装依赖
npm install

# 启动开发服务
npm run dev
